# Lista de Tarefas - HTML, CSS, JS + FastAPI

Sistema de gerenciamento de tarefas full-stack, com front-end em HTML/CSS/JavaScript puro e back-end em Python usando FastAPI.

## 🚀 Funcionalidades

- Adicionar tarefas
- Visualizar lista de tarefas
- Marcar tarefas como concluídas
- Remover tarefas

## 🛠️ Tecnologias utilizadas

**Front-end:**
- HTML5
- CSS3
- JavaScript (Fetch API)

**Back-end:**
- Python
- FastAPI
- Uvicorn

## ▶️ Como rodar o projeto localmente

### Back-end
\`\`\`bash

cd Backend

pip install fastapi uvicorn

uvicorn main:app --reload

\`\`\`

### Front-end
Abra o arquivo \`index.html\` da pasta \`Frontend\` com o Live Server (ou extensão equivalente).

## 📌 Sobre o projeto

Este projeto foi desenvolvido como forma de praticar a integração entre front-end e back-end, conectando uma interface feita em JavaScript puro a uma API REST construída com FastAPI.
